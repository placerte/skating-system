# handoff-260216-1.md

# Scope / Problem Framing

The Skating System ranking engine (Rules 5–7 for individual dances) is producing correct final placements, but the generated transcript is insufficiently expressive.

The objective of this handoff is to upgrade transcript generation without modifying ranking logic.

The transcript must:
- Be deterministic
- Be structurally consistent
- Explicitly narrate Rule 5 → Rule 6 → Rule 7 escalation
- Match the refined transcript model defined in `rule_5_6_7_transcript_refined.md`

Ranking results must remain identical.

---

# Specs

## S-260216-1.1 — Transcript Must Be Place-Centric

Each rank attribution must begin with:

- "Attempting to attribute rank X"
- Explicit list of current candidates

This must occur for every rank 1..N.

---

## S-260216-1.2 — Column Usage Must Be Explicit

Every evaluation step must state:

- "Using column \"1–t\" counts" when applying Rule 5 or Rule 6
- "Using column \"1–t\" sums" when applying Rule 7

No implicit column changes are allowed.

---

## S-260216-1.3 — Rule Escalation Must Be Narrated

Escalation chain must be explicit:

- Rule 5 — Majority found / no majority / majority tie
- Rule 6 — Greater majority or equal majority persists
- Rule 7 — Smaller sum or equal sum persists
- Escalation to next column must be narrated explicitly

No silent escalation.

---

## S-260216-1.4 — Rank Block Detection

When a majority tie occurs under Rule 5 that spans multiple ranks:

- Transcript must declare a "Rank block detected for ranks X and Y"
- Resolution inside the block must be nested and indented

Block resolution must not re-list eliminated candidates.

---

## S-260216-1.5 — Final Attribution Formatting

Final assignment lines must be visually emphasized:

**Rank X attributed to ENTRY_ID**

No additional commentary after final attribution line for that rank.

---

# Implementation

## I-260216-1.1 — Do Not Modify Ranking Logic

The following methods must remain functionally unchanged:

- `_find_place()`
- `_resolve_majority_tie()`

Only transcript node creation and labeling may change.

---

## I-260216-1.2 — Introduce Structured Transcript Nodes

DecisionNode tree must explicitly include nodes for:

- Place attempt header
- Candidate set context
- Column usage declaration
- Rule application result
- Escalation notice
- Rank block detection

Do not infer narrative at render time; narrative must be encoded during solving.

---

## I-260216-1.3 — Correct Rule Labeling

- "Majority tie at t" remains Rule 5 (not Rule 6)
- "Advance to next t" must not be labeled Rule 8
- Rule 6 only when comparing greater majority
- Rule 7 only when comparing sums

---

## I-260216-1.4 — Preserve Deterministic Ordering

Transcript must list candidates in the exact order they are evaluated.

No sorting changes are allowed.

---

# Tests

## T-260216-1.1 — Rule 5 Example Reproduction (Literal Fixture)

Create a pytest test that asserts the transcript text **exactly equals** the Rule 5 transcript fixture.

- The expected transcript must be stored as a literal multi-line string fixture (or a `.txt` fixture file loaded verbatim).
- The produced transcript must match **character-for-character**, including:
  - indentation
  - punctuation
  - en-dash in "1–t"
  - blank lines (if any)

The fixture content is the Rule 5 section in `rule_5_6_7_transcript_refined.md`.

---

## T-260216-1.2 — Rule 6 Tie Case (Literal Fixture)

Create a pytest test that asserts the transcript text **exactly equals** the Rule 6 transcript fixture.

Coverage requirements:

- Majority tie detection under Rule 5
- "Rank block detected for ranks X and Y"
- Nested block resolution
- Rule 6 greater-majority resolution

The fixture content is the Rule 6 section in `rule_5_6_7_transcript_refined.md`.

---

## T-260216-1.3 — Rule 7 Equal Majority + Equal Sum + Next Column (Literal Fixture)

Create a pytest test that asserts the transcript text **exactly equals** the Rule 7 transcript fixture.

Coverage requirements:

- Equal majority under Rule 6
- Escalation to Rule 7 sums
- Equal sum persists
- Escalation to next column
- Final resolution via Rule 6 (greater majority at later column)

The fixture content is the Rule 7 section in `rule_5_6_7_transcript_refined.md`.

DoD-260216-1.2 — Final placements are unchanged compared to pre-handoff version.
